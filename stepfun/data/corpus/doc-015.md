# IK 分词器的 smart 与 max_word 模式对比

IK 是中文全文检索里最常用的分词器，它同时维护三套词典：核心词典、量词词典和停用词词典。分词模式有 `smart` 和 `max_word` 两种，前者做最细粒度歧义消解，后者会把同一个词切出尽可能多的组合。

`smart` 模式是我们在知识库上的默认选择。它会利用词频和歧义统计选择最合理的切法，"笔记本"不会被切成"笔记"加"本子"这种无意义的组合，全文检索的精确率和召回率都比较均衡。

`max_word` 模式切得更碎，"北京大学"会被切成"北京"和"北京大学"两种候选。好处是召回更全，坏处是索引体积膨胀、查询得分被稀释，而且用户搜"北京大学"时，"北京"这个高频词会把一堆只提到北京但和主题无关的文档也拉进来。

我们实测过在两千篇规模的中文语料上，`max_word` 的倒排链长度大约是 `smart` 的两倍半，召回率只多涨两个百分点，nDCG 反而略降，因为排序质量变差了。

中文还有一组特殊情况需要留意。型号、版本号、英文缩写混排的字符串，比如 `seekdb 1.4.0` 或者 `bge-small-zh-v1.5`，不同模式的切法差异很大。我们把这类词通过自定义词典加进去，避免它们被切碎。

另外，IK 的词典是静态加载的，内存占用在长尾词典配置下会明显上升。选一个适中的词典规模加上针对自己领域的自定义扩展，是比较经济的选择。

结论：默认用 `smart`，只在明确需要极限召回的场景才临时切到 `max_word`，并且切换之后要重新灌数据，因为索引的切词结果已经固化了。
