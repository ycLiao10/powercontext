# BM25 打分的机制与参数

BM25 是全文检索最经典的打分函数，核心是三部分的组合：词频因子、文档长度归一化和逆文档频率因子。

词频因子衡量一个词在文档里出现得越多说明相关性越高，但它有饱和效应，出现二十次和出现五十次的差别远小于出现一次和出现两次的差别。参数 k1 控制这个饱和速度，常见取值在一点二到两点之间。

文档长度归一化用参数 b 控制。它衡量文档长度相对于平均长度的偏离，短文档里的词天然更容易显得重要，所以要给它们一点惩罚。b 取零表示完全不做长度归一化，取一表示完全按长度调整。

逆文档频率因子衡量词的普遍性。一个在所有文档里都出现的词几乎没有区分度，它的 idf 会很低；一个只出现在少数文档里的词 idf 很高。BM25 的 idf 有个下限截断，避免在语料极小时算出负值。

三个参数里对我们影响最大的是 b。我们的语料段落长度分布不均，有的段落两百字，有的接近八百字，把 b 从默认值调低到 0.3 之后 nDCG 提升了大约两个百分点，因为长段落里的高频词不再主导排序。

但 BM25 的强项正好是向量检索的弱项。BM25 只看字面匹配，"汽车"和"轿车"互相不认。要让全文路能处理同义表达，只能靠同义词扩展表把词映射到同一组 idf 上，这让打分逻辑变得脆弱。

所以我们的结论是全文路在混合检索里承担精确匹配和专有名词兜底的作用，语义泛化交给向量路。理解了各自的能力边界，融合策略才好定。
