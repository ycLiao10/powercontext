把散落在多个 .md/.txt 里的资料导入，工作台负责切分、建索引、混合检索， 每条结果都带文献名、第几段、字符区间；读过的文献由 PowerContext 记入长期记忆，下次检索时参与排序。

01 / 问题

三个反复出现的小麻烦

出处找不回来

记得「某篇文档里讲过 BM25 和向量怎么结合」，但翻不到是哪一篇、哪一段。只给文件名的搜索解决不了这个。

换个说法就搜不到

关键词索引只认字面：写「融合排序」能搜到，写「把两路结果合到一起排」就漏召回。纯关键词不够。

读过就忘

这周读了三篇 RAG 评测，下周只记得「读过」。阅读偏好、已读清单散落在脑子里，工具也不会替你记住。

02 / 功能

导入一次，检索两条通道，记忆跨会话保留

01

导入与切分

粘贴正文或选择 .md/.txt，按段落与句末切成约 600 字的分块，记录每块的字符偏移，为出处定位打底。

02

混合检索

词法通道用 SQLite FTS5 三元组索引（中文可用），向量通道用本地 bge-small-zh-v1.5；两路候选按 RRF（k=60）融合，只看名次、不混量纲。

03

出处定位

每条结果返回「文献名 + 第 N 段 + 字符区间 + 原文片段」，并标注它来自词法、向量还是两条通道同时命中。

04

阅读记忆

导入时把每块来源与文献记忆写入 PowerContext；检索时读取同一 Scope 的记忆，命中已读文献的结果获得 1.15 倍加权，偏好也能手动沉淀。

    05 / 验证

    可复现的两组验证

    06 / 运行

    三个终端，从零跑起来

    需要 Python 3.11+；嵌入模型约 100 MB，首次启动自动下载到 qoder/data/models。

    终端 A本地嵌入服务

    pip install "fastembed==0.9.1" truststore
cd qoder
python tools/embed_server.py --port 8081
curl -s http://127.0.0.1:8081/health

    期望返回 "dimension": 512。

    终端 BPowerContext

    uv tool install --force "powercontext[cli,server]==1.2.0"
cd qoder
cp .env.example .env   # 取消 embedding 段注释并填绝对路径
powercontext config validate --env-file .env
powercontext server run --env-file .env

    /v1/capabilities 的 search_modes 应包含 vector、hybrid。

    终端 C工作台

    cd qoder
python -m app --port 8080

    打开 http://127.0.0.1:8080：导入 → 检索 → 看出处与记忆加权。
